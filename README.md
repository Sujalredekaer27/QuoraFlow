# 🚀 QuoraFlow

**QuoraFlow** is a modern, full-stack RESTful application built with Node.js and Express. It serves as a simplified social media feed where users can share, edit, and manage posts in a clean, card-based interface.



---

## ✨ Features
- **Full CRUD Support**: Create, Read, Update, and Delete posts seamlessly.
- **RESTful Routing**: Architecture designed around standard REST principles.
- **Dynamic Styling**: A responsive, modern UI with a focus on typography and visual hierarchy.
- **Unique Identification**: Every post is assigned a unique `UUID` for secure data handling.
- **Method Override**: Support for `PATCH` and `DELETE` requests directly from HTML forms.

---

## 🛠️ Tech Stack
- **Backend**: Node.js, Express.js
- **Frontend**: EJS (Embedded JavaScript Templates), Modern CSS3
- **ID Generation**: UUID (v4)
- **Middleware**: Method-Override, Body-Parser
